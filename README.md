# Hanser 形象项链工程包

本仓库用于管理一条 Hanser 形象定制项链从概念、设计、询价、打样到量产验收的全过程。

> 材料口径：饰品行业常把 316L 不锈钢称作“钛钢”，但它不是钛或钛合金。所有合同、BOM、图纸和检测报告都应写明 **316L stainless steel / SUS316L**，不要只写“钛钢”。

## 从这里开始

1. 打开 [当前项目状态](PROJECT-STATUS.md)，完成剩余 G1 决策。
2. 阅读 [完整工程流程](docs/01-engineering-flow.md)。
3. 查看 [概念效果图基线](design/concept/CONCEPT-BASELINE-v0.1.md)。
4. 按 [效果图到工程文件](docs/06-concept-to-engineering.md) 完成矢量化、结构定义和询价包。
5. 在 [需求冻结表](docs/02-product-brief.md) 中补齐所有 `待定` 项。
6. 将 `factory-pack/templates/` 中的模板复制到对应批次目录，向至少 3 家工厂询价。
7. 打样前完成 G2 图纸冻结；量产前完成 G4 金样签署。

## 首版建议基线

适合当前全身 Q 版彩色效果图、小批量、以形象还原为主的路线：

- 吊坠：优先让工厂比较“316L 平面冲切/激光切割 + 蚀刻分区 + 彩色填充”和“316L 浅浮雕/铸造 + 彩色填充”。
- 毛怪：固定一体版作为成本基线，独立旋转版单独报价和打样。
- 颜色：效果图为多色设计，具体使用滴油、烤漆或其他工艺由工厂 DFM；PVD 更适合金属底色，不应默认等同于图案多色填充。
- 链条：直接采用工厂成熟标准链型，不在首版定制链节。
- 尺寸：当前细节量不适合直接沿用 28–32 mm，先比较 70 mm 的 1:1 纸样和工厂最小特征建议。
- 交付：先做 1–3 件工程样，再做 5–20 件小批试产，合格后才扩大批量。

以上只是启动基线，最终尺寸、壁厚、公差和表面效果必须由选定工厂完成 DFM 并写入签字版图纸。

## 目录

```text
hanser-necklace/
├─ README.md
├─ docs/                         # 决策、流程、规格、制造和验收规则
├─ design/
│  ├─ image/                    # 生成迭代图、最终 PNG 与 PSD 工作源文件
│  ├─ references/               # 经授权的形象参考、品牌色、姿态参考
│  ├─ concept/                  # 草图和方案评审图
│  ├─ vector/                   # SVG/AI/DXF 等二维源文件
│  ├─ cad/                      # 参数化 CAD 原始文件
│  ├─ render/                   # 渲染及 1:1 纸样
│  └─ release/                  # 每个冻结版本的只读发布包
├─ factory-pack/
│  ├─ templates/                # RFQ、DFM、样品和 QC 模板
│  ├─ supplier-quotes/          # 报价及供应商比较
│  └─ batches/                  # 每次打样/量产批次记录
├─ quality/
│  ├─ approved-sample/          # 金样照片、封样编号、签署页
│  ├─ inspection/               # 来料、过程、出货检验记录
│  └─ test-reports/             # 材质、镍释放等第三方报告
└─ changes/                     # 变更申请与版本日志
```

空目录通过 `.gitkeep` 保留。大体积 CAD、渲染和检测文件建议启用 Git LFS；签约后不要把供应商账户、身份证、电话等隐私资料提交到公开仓库。
