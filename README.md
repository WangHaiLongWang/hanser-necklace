# Hanser 形象项链工程包

本仓库用于管理一条 Hanser 形象定制项链从概念、设计、询价、打样到量产验收的全过程。

> 材料口径：饰品行业常把 316L 不锈钢称作“钛钢”，但它不是钛或钛合金。所有合同、BOM、图纸和检测报告都应写明 **316L stainless steel / SUS316L**，不要只写“钛钢”。

## 从这里开始

1. 打开 [当前项目状态](PROJECT-STATUS.md)，先完成 G1 的 7 项输入。
2. 阅读 [完整工程流程](docs/01-engineering-flow.md)。
3. 在 [需求冻结表](docs/02-product-brief.md) 中补齐所有 `待定` 项。
4. 用 [制造与 DFM 指南](docs/03-manufacturing-dfm.md) 选工艺并约束设计。
5. 将 `factory-pack/templates/` 中的模板复制到对应批次目录，向至少 3 家工厂询价。
6. 打样前完成 G2 图纸冻结；量产前完成 G4 金样签署。

## 首版建议基线

适合第一次、小批量、以形象还原为主的路线：

- 吊坠：316L 不锈钢，双面或单面浅浮雕，失蜡铸造 + 手工修整 + 镜面/细拉丝组合。
- 颜色：首版优先钢本色；如需金色或彩色，使用明确膜层规范的 PVD，并额外做色差及耐磨确认。
- 链条：直接采用工厂成熟标准链型，不在首版定制链节。
- 尺寸：吊坠高约 28–32 mm（不含吊环），先纸样 1:1 佩戴确认后冻结。
- 交付：先做 1–3 件工程样，再做 5–20 件小批试产，合格后才扩大批量。

以上只是启动基线，最终尺寸、壁厚、公差和表面效果必须由选定工厂完成 DFM 并写入签字版图纸。

## 目录

```text
hanser-necklace/
├─ README.md
├─ docs/                         # 决策、流程、规格、制造和验收规则
├─ design/
│  ├─ references/               # 经授权的形象参考、品牌色、姿态参考
│  ├─ concept/                  # 草图和方案评审图
│  ├─ vector/                   # SVG/AI/DXF 等二维源文件
│  ├─ cad/                      # 参数化 CAD 原始文件
│  ├─ render/                   # 渲染及 1:1 纸样
│  └─ release/                  # 每个冻结版本的只读发布包
├─ factory-pack/
│  ├─ templates/                # RFQ、DFM、样品和 QC 模板
│  ├─ supplier-quotes/          # 报价及供应商比较
│  └─ batches/                  # 每次打样/量产批次记录
├─ quality/
│  ├─ approved-sample/          # 金样照片、封样编号、签署页
│  ├─ inspection/               # 来料、过程、出货检验记录
│  └─ test-reports/             # 材质、镍释放等第三方报告
└─ changes/                     # 变更申请与版本日志
```

空目录通过 `.gitkeep` 保留。大体积 CAD、渲染和检测文件建议启用 Git LFS；签约后不要把供应商账户、身份证、电话等隐私资料提交到公开仓库。
