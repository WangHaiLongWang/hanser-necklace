# 版本、命名与交付物

## 版本规则

- 工作版本：`v0.1`, `v0.2`……尚未批准生产。
- 首次发布：`v1.0`。只有通过 G2 的文件能进入 `design/release/v1.0/`。
- 不改变装配/外观意图的小修订：`v1.1`。
- 改变轮廓、尺寸、结构、材料、表面处理或需要重打样：`v2.0`。
- 禁止覆盖已发布文件。修改源文件后创建新发布目录，并用变更单说明影响。

推荐文件名：

```text
HN-PENDANT-3D-v1.0.step
HN-PENDANT-MESH-v1.0.stl
HN-PENDANT-DWG-v1.0.pdf
HN-NECKLACE-BOM-v1.0.xlsx
HN-FINISH-MAP-v1.0.pdf
HN-RENDER-FRONT-v1.0.png
```

## G2 设计发布包清单

- [ ] 产品需求冻结页
- [ ] 受控 PDF 工程图

- [ ] STEP 实体交换文件
- [ ] STL 网格文件及导出精度说明
- [ ] DXF/SVG（如有二维轮廓或激光图案）
- [ ] BOM：吊坠、链、扣、连接环、焊料/附件、包装
- [ ] 表面处理区域图与颜色/光泽参考
- [ ] 正、背、侧面渲染及 1:1 打印页
- [ ] 版本变更记录

## 工厂回传包清单

- [ ] 已回签的图纸与 DFM 结论
- [ ] 正式报价：样品、模具/治具、单价阶梯、包装、测试、税运
- [ ] 样期、量产周期、报价有效期和 MOQ
- [ ] 模具/治具所有权及保管条款
- [ ] 样品检验记录和多角度照片
- [ ] 材质/表面处理/合规报告
- [ ] 量产批次检验报告与出货清单

## 变更流程

任何人在金样后提出变化，都要填写 `changes/CHANGELOG.md` 中的新条目，评估：

- 是否影响 CAD、图纸、BOM、报价、交期或已有模具；
- 是否需要新样品、新检测或重新签署金样；
- 已生产半成品如何处置；
- 新旧版本切换批次和追溯方式。
