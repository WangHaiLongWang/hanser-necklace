# 制造路线与 DFM 指南

## 先选路线

| 路线 | 适合 | 优点 | 局限 |
|---|---|---|---|
| 失蜡铸造 316L | 立体/浅浮雕，小到中批量 | 造型自由，单位成本随批量下降 | 收缩、砂眼、抛光吃细节，需模具与金样 |
| CNC 雕刻/铣削 | 几何造型、平面浮雕、小批 | 尺寸稳定、无铸造气孔 | 深腔和复杂倒扣受刀具限制，工时较贵 |
| 激光切割 + 激光雕刻 | 扁平轮廓、线稿款 | 启动快、无需复杂模具 | 立体感有限，切边需去毛刺和抛光 |
| 金属 3D 打印 | 极少量复杂验证 | 不必传统模具、复杂度高 | 表面粗、后处理多、单价高，量产一致性需验证 |
| 冲压 | 大批量薄片款 | 量产快、单价低 | 模具费高，不适合早期频繁改版 |
| 平面金属坯 + 蚀刻/凹槽 + 彩色填充 | 多色卡通图案、中小批量 | 色块边界清楚，较贴合当前效果图 | 细小色块、附着力和金属隔断宽度受工厂能力限制 |
| UV 彩印 + 透明保护层 | 多色渐变、小批量验证 | 能保留插画细节、启动较快 | 耐磨、耐汗和长期贴肤性能需验证，外观不同于金属分色 |

当前 `CONCEPT-v0.1` 为多色平面角色。首版至少比较“316L 平面金属坯 + 凹槽/蚀刻 + 彩色填充”和“316L 浅浮雕/铸造 + 彩色填充”；若 20 件预算无法满足，再将 UV 彩印作为验证方案单列，不要在未说明的情况下替换工艺。

## 启动参数（用于概念设计，不替代工厂 DFM）

| 特征 | 建议启动值 | 验证方式 |
|---|---:|---|
| 铸造主体最小名义厚度 | 1.5 mm 以上，推荐约 1.8–2.5 mm | 工厂结合面积、流道和变形复核 |
| 可见凸/凹线宽 | 0.30 mm 以上，关键线建议 0.40 mm 以上 | 实物样确认抛光后是否保留 |
| 浅浮雕高度差 | 0.30–1.20 mm | 侧光检查层级与积污 |
| 外露边缘圆角 | R0.30 mm 起，贴肤侧更圆滑 | 触摸、棉布刮擦和佩戴测试 |
| 吊环有效间隙 | 链条/连接环最大外径 + 至少 0.5 mm | 实物装配并拉动检查 |
| 活动连接环线径 | 约 1.0–1.5 mm 起 | 工厂按重量与拉力复核 |
| 文字/标记 | 避免过小；以样品清晰可读为准 | 打样后定义限度样 |
| 彩色填充金属隔断 | 概念起点 0.30–0.50 mm | 由工厂按其蚀刻/填色能力书面确认 |
| 独立色块最小宽度 | 概念起点 0.50 mm 以上 | 以实际尺寸样和工厂同类样件验证 |
| 活动件边缘间隙 | 不预设通用值 | 由轴径、涂层厚度和旋转要求共同确定 |

这些数值是保守的沟通起点，不是通用公差。最终数值要写在工厂回签的工程图上。

## CAD 与图纸要求

- 建模单位统一为 mm，模型置于明确原点和正视方向。
- 保留参数化源文件；对外至少输出 STEP（实体交换）、STL（样件/网格）和 PDF 工程图。仅二维款另交 DXF/SVG。
- 3D 模型表达“名义成品”；工厂添加的缩水补偿、浇道、支撑不得反写覆盖我方母版。
- 图纸至少标总高、总宽、厚度、吊环内径、关键圆角、链长、关键装配间隙和目标重量。
- 每个表面用区域图指明镜面、拉丝、喷砂、凹部氧化/PVD 等效果；“高级感”“差不多亮”不可作为验收语言。
- 只给真正影响功能/外观的尺寸公差。普通装饰外形可由工厂提出通用公差，关键装配位单独标注。

## 材料与表面处理

- BOM 和订单写 `SUS316L / 316L stainless steel`；要求原料批次证明或成分检测，不接受只写“环保钛钢”。
- 链、扣、连接环、焊料和吊坠分别列材质；吊坠是 316L 不代表整条项链都是 316L。
- 贴肤件要求无锐边、毛刺、残余抛光蜡和明显焊瘤。要求工厂说明清洗、钝化及防锈处理。
- PVD 颜色必须固定基材前处理、膜系、目标色板/金样和允许色差；链条与吊坠可能因供应批次产生色差。
- 多色图案应逐色编号并匹配实体色板或签字金样。屏幕 RGB、PNG 高光和半透明阴影不能直接作为量产颜色依据。
- 让工厂区分滴油、烤漆、软珐琅、硬珐琅、UV 彩印等真实工艺；要求提交同材质、同工艺样件和耐磨/汗液风险说明。
- 若面向市场销售，应按销售地区和使用人群确认适用法规与测试。可向检测机构询问镍释放、铅/镉等项目；在中国销售可核对现行的饰品有害元素限量要求，在欧盟销售需核对 REACH 及相关镍释放方法。不要仅凭“316L”推定合规。

## 毛怪活动件专项 DFM

- 固定版与旋转版必须使用不同料号、图纸和报价，不能用同一张效果图口头区分。
- 旋转版图纸应包含轴/铆钉材质、轴径、头径、有效长度、轴向间隙、背面收口、防脱方式和允许转角。
- 毛怪与头发之间要有足够重叠承载轴孔；轴孔不得落在单根发丝、尖角或狭窄边缘。
- 旋转时不得刮擦人物脸部、手指或相邻色层，也不得露出尖锐轴尾。
- 工程样至少验证自然摆动、手动反复转动、轻拉、防脱、贴肤侧刮擦和上色磨损；次数与判定标准由双方在下单前书面确认。
- 若活动件无法在预算和安全要求内实现，默认回退到固定一体版，但必须由用户书面批准。

## 工厂必须书面回答的 DFM 问题

1. 使用哪种 316L 原料形态和牌号证明？铸造件是否能提供批次成分记录？
2. 预计铸造/烧结/抛光后缩水和变形在哪里？由谁在什么文件中做补偿？
3. 浇口、分模线、支撑或夹具痕放在哪里？修整后允许痕迹是什么？
4. 哪些细节在抛光后会变钝或消失？建议最小线宽/深度是多少？
5. 是否存在藏抛光膏、积水或勾衣的深腔、锐角、薄弱点？
6. 吊环、焊点和连接环的建议结构与拉力能力是什么？如何检验？
7. 表面处理每道工序是什么？PVD 的膜层体系、色板和耐久验证是什么？
8. 模具/治具费、所有权、保存期限、维修和再次生产费用如何约定？
9. 当前多色色块适合哪种填充/印刷工艺？最小金属隔断、最小色块和允许色差是多少？
10. 毛怪固定版和旋转版分别如何制造？旋转轴、防脱、背面触感和耐久如何验证？
