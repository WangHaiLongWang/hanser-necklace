# 珍珠链与顶部接环规格

## 已确定

- 链条形式：珍珠链（工程定义仍需细化）。
- 名义长度：60 cm。
- 扣件：单接扣。
- 延长链：不设置，如后续变更需升版。
- 吊坠：顶部预留承力接环。

## 珍珠链还必须确认

| 参数 | 需要填写 | 影响 |
|---|---|---|
| 珠体类型 | 天然/养殖珍珠、贝珠、玻璃/树脂仿珠、金属波珠链 | 成本、重量、耐磨、连接结构和材料声明 |
| 珠径 | 建议先让工厂提供 4/5/6/8 mm 对比 | 外观比例、重量、孔径和接环尺寸 |
| 形状 | 正圆、近圆、米形、巴洛克等 | 外观与串制间隙 |
| 颜色/光泽 | 白、米白、蓝白等，并以实体样为准 | 与吊坠白/蓝色匹配 |
| 珠孔 | 孔径和边缘质量 | 决定串线直径和断裂风险 |
| 串制材料 | 珠宝线、尼龙线、包胶钢丝或金属连接 | 柔软度、寿命和承重 |
| 串制方式 | 是否逐珠打结、双线、压线管 | 断线后散珠风险和成本 |
| 端头结构 | 包珠、夹线扣、线护圈、压线管等 | 与单接扣和吊坠连接可靠性 |
| 长度口径 | 60 cm 是否包含扣件 | 成品验收尺寸 |
| 长度公差 | 工厂建议并写入图纸 | 批次一致性 |

如果这里的“珍珠链”实际指金属波珠链，则应改写为“316L 波珠链”，并确认波珠直径、连接节距和波珠链专用连接扣；不需要珍珠串线、打结和端头夹线结构。

## 单接扣还必须确认

- 扣型：龙虾扣、弹簧扣、鱼钩扣、磁吸扣、桶扣或波珠链连接扣。
- 扣件主体、弹簧、轴和焊料的材料。
- 扣件尺寸、开口宽度和开合方向。
- 与珍珠链端头如何连接，是否需要中间连接环。
- 成品拉力目标、循环开合次数和防松要求。

“单接扣”只说明数量，不能代替扣型和结构规格。建议提供一张目标扣件照片或选择工厂标准型号。

## 顶部接环还必须确认

| 参数 | 工程要求 |
|---|---|
| 位置 | 根据吊坠质量中心确定，不能只按几何中心放置 |
| 数量 | 默认 1 个；若单环无法防侧翻，可评估双连接点或转向连接环 |
| 内径 | 至少大于链端/连接环最大外径 0.5 mm，并保留装配空间 |
| 截面宽度/线径 | 由吊坠预计重量和拉力目标决定 |
| 厚度 | 与主体厚度及焊接/一体结构匹配 |
| 平面方向 | 确保穿链后吊坠正面朝前，不侧翻、不翻背 |
| 结构 | 优先一体闭环或焊闭结构；不接受未经确认的开口环直接承重 |
| 边缘 | 圆角、去毛刺，不能割线或刮伤珠体 |
| 表面 | 与吊坠金属边颜色和光泽一致 |

## 由于吊坠较大的专项风险

当前图案为 80 × 56.72 mm，重量尚未知。工程方必须：

1. 按建议主体厚度估算吊坠净重。
2. 确认珍珠链、串线、端头、单接扣和顶部接环的安全承载能力。
3. 装配后进行自然悬挂和翻转测试。
4. 对成品做约定拉力测试；测试值由工程方结合预计重量提出并回签。
5. 检查接环和金属边不会磨损珍珠涂层、割断串线或勾衣。

## 工程样验收

- 60 cm 长度及公差合格。
- 珠径、颜色、光泽和表面缺陷符合金样。
- 珠串顺滑，无异常露线、松动或锐利端头。
- 单接扣开合顺畅且不自行松脱。
- 吊坠自然朝前，不明显侧倾或翻背。
- 接环与链端自由活动但不过度晃动。
- 拉力后无断线、散珠、接环张开、焊点开裂或扣件失效。
